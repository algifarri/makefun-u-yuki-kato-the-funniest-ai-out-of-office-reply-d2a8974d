## Entry

`main.py` (stdlib-only, deterministic, no network) writes a single
out-of-office auto-reply to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR`
to change the output directory when testing locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/ooo-test python3 main.py
cat /tmp/ooo-test/entry.txt
```
